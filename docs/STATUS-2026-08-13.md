  `query_engine-windows.dll.node` while `next dev` holds it open. Use
  `npx next build` (the client is already generated), or move `prisma generate`

## Testing on a phone without deploying

```powershell
$env:DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:5432/ledgerly"
$env:DIRECT_URL="postgresql://postgres:postgres@127.0.0.1:5432/ledgerly"
npx next dev -H 0.0.0.0
ipconfig      # note IPv4, e.g. 192.168.1.7
```

Open `http://192.168.1.7:3000` on the phone, same Wi-Fi. Real touch, real
keyboard, real `pointer: coarse`.

**The `$env:` lines are not optional.** `npm run dev` reads `.env`, which points
at production Supabase. This session began by nearly stress-testing real
financial records because of exactly that.

## Decisions worth not relitigating

- **Personal share vs cash outflow** — both are shown; the preference only
  chooses which is larger. Budgets, alerts and exports are deliberately
  unaffected.
- **`2500+18%` = ₹2,950**, not ₹2,500.18. Context-sensitive, matching
  calculators and GST. The live preview is what makes that safe.
- **Preferences are cookies, not localStorage**, because the surfaces reading
  them are server components. Per-device, not per-user — a second user on the
  same browser inherits them. Open product question.
- **The keypad is touch-only.** Desktop keeps the physical keyboard, and the
  input stays typable everywhere so assistive tech is never forced through a
  custom widget.
